# 🧠 Quiz Game

A simple Python-based command-line quiz game that tests your knowledge about basic computer hardware concepts like CPU, GPU, RAM, ROM, and PSU.

## ✨ Features
- Interactive command-line interface
- Asks 5 multiple-choice computer-related questions
- Calculates score and percentage at the end
- Graceful exit if user doesn't want to play

## 🚀 How to Run

1. Make sure Python is installed on your system or extension in Visual Studio Code.
